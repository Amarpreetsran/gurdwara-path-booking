Bookings and bheta

All bookings, payments and receipts, as an Excel file.

When a devotee reports a UPI payment, check the UTR in your bank app, then tap "Confirm and issue receipt". Payments made at the gurdwara: "Record payment at gurdwara". Each confirmed payment gets a numbered receipt the devotee can see on "My booking".

Places at the same time

How many families can book each path for the same date and time. For example, 2 for Akhand Path if two can run together. Lowering a number never removes existing bookings; it only stops new ones above the limit.

Closed dates

No bookings can be made on these dates, for example gurpurabs or other programmes at the gurdwara.

Online payment (UPI)

Devotees pay with Google Pay, Paytm, PhonePe, BHIM or any bank's UPI app, straight to this UPI ID, with no fees. Set a bheta amount for each path (0 = no bheta asked online). Amounts apply to new bookings; existing bookings keep the amount they were booked at.

The first payment must be at least 20% of the bheta, paid online.
